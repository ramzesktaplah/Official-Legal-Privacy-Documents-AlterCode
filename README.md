# AlterCode - Official Legal & Privacy Documents

Official web application hosting the Privacy Policy and Terms & Conditions for the **AlterCode** mobile app.

[![StackBlitz](https://developer.stackblitz.com/img/open_in_stackblitz.svg)](https://stackblitz.com/~/github.com/ramzesktaplah/Official-Legal-Privacy-Documents-AlterCode)

---

## 📖 Overview

This repository contains the single-page web interface for displaying the official legal compliance and privacy documentation for **AlterCode**, an AI-powered mobile application. It presents users with clear, accessible, and responsive terms and privacy policies.

## ✨ Features

- **Tabbed Navigation:** Easily toggle between Privacy Policy and Terms & Conditions without reloading the page.
- **Responsive & Dark Theme UI:** Designed for both mobile and desktop screens with a clean dark theme palette.
- **Transparent Policies:** Details local storage behavior (SQLite), AI code transformation proxying, and Google AdMob advertising integrations.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Local Server:** [servor](https://github.com/lukejacksonn/servor) for zero-configuration local server setup with live reload

## 📂 Project Structure

```
├── index.html        # Main landing page containing Privacy Policy & Terms sections
```

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ramzesktaplah/Official-Legal-Privacy-Documents-AlterCode.git
   cd Official-Legal-Privacy-Documents-AlterCode
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm start
   ```

4. Open your browser and navigate to `http://localhost:8080` (or the port specified by `servor`).
